# Salus Protocol v1

**Salus** revolutionizes health insurance through Web3, smart contracts, and tokenomics to create an incentive-driven ecosystem. By securely sharing health data via Trusted Execution Environments (TEEs), users can earn Salus tokens or reduced insurance premiums, while maintaining control and privacy. Key features include:

- **Dynamic Health Scoring**: Real-time health data impacts insurance rates, rewarding healthy behaviors.
- **Tokenized Incentives**: Users earn tokens by sharing anonymized data, which is valuable for research and insurance companies.
- **Smart Contracts**: Automated policies ensure transparency and efficiency.

Salus empowers individuals to monetize health data, promotes medical research, and redefines insurance through fairness and privacy.

## How it Works
**Salus** enables users to share their health data securely while earning rewards and reducing insurance premiums:

- **Connect Wallet**: Users link their Web3 wallet to the platform.

- **Upload Data**: Health data from apps and wearables is uploaded.

- **Privacy-Preserving Sharing**: Data is anonymized and shared with insurers or researchers securely.

- **Earn Rewards**: Users earn Salus tokens for contributing data, with higher rewards for better data.

- **Lower Premiums**: Improved health metrics lead to reduced insurance premiums.

- **Governance**: Token holders can vote on platform decisions through the Salus DAO.

## Tech Stack
- Encrypting the data, running the computation, and decrytpting the data: LIT TEE
- User authentication and wallet for cashbacks and rewards: Privy.io
- Backend: Typescript, Node.js, Express
- Frontend: React

## Getting Started

Follow these steps to set up and run the project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/r-agni/ethglobalsf.git
   cd ethglobalsf/salus
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run build
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000` to view the app.
