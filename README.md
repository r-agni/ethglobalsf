# Salus Protocol v1

**Salus** revolutionizes health insurance through Web3, smart contracts, and tokenomics to create an incentive-driven ecosystem. By securely sharing health data via Trusted Execution Environments (TEEs), users can earn Salus tokens or reduced insurance premiums, while maintaining control and privacy. Key features include:

- **Dynamic Health Scoring**: Real-time health data impacts insurance rates, rewarding healthy behaviors.
- **Tokenized Incentives**: Users earn tokens by sharing anonymized data, which is valuable for research and insurance companies.
- **Smart Contracts**: Automated policies ensure transparency and efficiency.

Salus empowers individuals to monetize health data, promotes medical research, and redefines insurance through fairness and privacy.
